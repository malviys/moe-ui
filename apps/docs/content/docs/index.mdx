Moe UI is a source-copy component registry for **Next.js 16 App Router** projects. The CLI installs complete component source into your application, where it becomes yours to inspect, style, and evolve.

> Web first, native next. The `v0.1.0-beta.1` contract covers React 19 and modern desktop browsers. iOS and Android are part of the future architecture, not this release guarantee.

## Why source ownership?

There is no runtime `@moe-ui/components` dependency. Components are built from React Native primitives, rendered through React Native Web, and styled with Uniwind. You can change every line while retaining an accessible behavioral foundation.

- **Auditable:** implementation and dependencies are visible in your repository.
- **Adaptable:** variants, spacing, and product-specific behavior live beside your app.
- **Reproducible:** registry items are versioned, checksummed, and generated from one canonical source.
- **Accessible:** browser and interaction checks are release gates rather than aspirational labels.

## Beta contract

| Included | Not included |
| --- | --- |
| 31 source-owned components | iOS or Android release support |
| Next.js 16 App Router | Pages Router or JavaScript projects |
| React 19 and React Native Web 0.21 | New components such as Command, Toast, or Form |
| Chromium, Firefox, and WebKit verification | A traditional component runtime package |
