## Props

### Avatar

| Prop        | Type     | Default | Description            |
| ----------- | -------- | ------- | ---------------------- |
| `className` | `string` | -       | Additional CSS classes |

### AvatarImage

| Prop     | Type                  | Default | Description      |
| -------- | --------------------- | ------- | ---------------- |
| `source` | `ImageSourcePropType` | -       | The image source |

### AvatarFallback

| Prop      | Type     | Default | Description                            |
| --------- | -------- | ------- | -------------------------------------- |
| `delayMs` | `number` | `0`     | Time to wait before rendering fallback |
